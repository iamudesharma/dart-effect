# dart-package-quality

Read pubspec.yaml, architecture and feature matrix; inputs include supported SDK and advertised operations. Run dart format lib test example tool, dart analyze, dart test and analyzer fixture harness. Run examples and compile example/web.dart with dart compile js. Check no dart:io in lib and explicit common E/R composition. Output verified commands and remaining gates; do not equate web compilation with browser behavioral validation or publish packages.

References resolve from the repository root; material stays in references/effect, outside this skill.
